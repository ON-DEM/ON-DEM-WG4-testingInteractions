# Figure Generation Script

## Overview

`make_figure_pub.py` generates high-quality figures and error metric tables for comparing DEM simulations with analytical solutions.

## Usage

```bash
python3 I_make_figure.py SOFTWARE_LABEL TEST_ID
```

**Examples:**
```bash
python3 I_make_figure.py YADE 1
python3 I_make_figure.py YADE 5
```

## Directory Structure

The script should be placed in the `make_figures/` folder:
```
project_root/
├── functions/
│   └── make_figure_pub.py  (this script)
├── output_ANA/
│   └── theoretical_output_test_XX.csv
├── output_DEM/
    └── dem_output_YADE_test_XX.csv  (or other software name)
```

**Note:** The DEM output folder is always `output_DEM`. Only the filename varies with the software label (e.g., `dem_output_YADE_test_01.csv`).

## Outputs

The script generates two types of output files in the `make_figures/` directory:

### 1. Figures

Publication-quality plots saved in both PDF and PNG formats:
- **Test 1 & 2**: 2D plot of $F_{i,x}$ vs time
- **Test 3**: 3D plot of $F_{i,y}$ and $F_{i,z}$ vs time
- **Test 4**: 3D plot of $F_{i,x}$ and $F_{i,y}$ vs time
- **Test 5**: 3D plot of $F_{i,x}$ and $F_{i,z}$ vs time

Filenames:
- `figure_test_XX.pdf`
- `figure_test_XX.png`

### 2. LaTeX Error Tables

Error metrics in LaTeX table format:
- Filename: `errors_test_X_SOFTWARE_LABEL.txt` (no leading zeros)
- **Ready to include** directly in your LaTeX document (no table wrapper)
- Simplified format showing only:
  - **MAPE$_i$**: Mean Absolute Percentage Error for particle i (%)
  - **MAPE$_j$**: Mean Absolute Percentage Error for particle j (%)
- Three significant figures
- Values below 10^-14 % shown as "< 10^-14"
- Includes vector notation in quantity names
- Contains MAPE metrics for:
  - Position $\vec{x}$
  - Velocity $\vec{v}$
  - Orientation $\vec{q}$ (quaternion)
  - Angular velocity $\vec{\omega}$
  - Force $\vec{F}$
  - Torque $\vec{T}$
  - Force inbalance (Newton's 3rd law check)
  - Torque inbalance (Newton's 3rd law check)

## Figure Styling

**Analytical data:**
- Dark purple solid line (`#4B0082`)
- Continuous representation

**DEM data:**
- Light green filled circles (RGB: `0.1020, 0.8000, 0.1020`)
- Downsampled to ~70 points for visibility
- Black edge outline
- Smaller marker size (3pt for 2D, 20pt for 3D)

**Other elements:**
- Very faint background grid (alpha 0.15)
- Thin black line at zero
- Boxed axes (all spines visible)
- No legend or title (publication-ready)
- Tight x-axis limits (0 to $t_{max}$)
- Scientific notation for axes > 1000
- Compact size: 3.2" × 2.4" (2D), 3.5" × 3.0" (3D)

**3D plots:**
- Force axis limits set to round numbers
- All axis limits properly enforced

## Error Metrics

### MAPE Calculation (Mean Absolute Percentage Error)

For each quantity (position, velocity, force, etc.):

$$ER_i = \frac{\sum |x_{DEM,i} - x_{ANA,i}|}{t_{max}}$$

$$N = \frac{\sum (|x_{ANA,i}| + |x_{ANA,j}|)}{t_{max}}$$

$$MAPE_i = 100 \times \frac{ER_i}{N}$$

The MAPE values are expressed as percentages, making them easy to interpret.

### Quantities Measured

**Per-particle metrics:**
- Position magnitude
- Velocity magnitude
- Orientation (quaternion norm)
- Angular velocity magnitude
- Force magnitude
- Torque magnitude

**Balance checks (Newton's 3rd law):**
- Force inbalance: $|\vec{F}_i + \vec{F}_j|$ (should be zero - equal and opposite)
- Torque inbalance: $|\vec{T}_i - \vec{T}_j|$ (should be zero - both use their own centers as reference)

These should be near zero if forces/torques are correctly computed. Values below machine precision (< 10^-14) are displayed as "< 10^-14" in the table.

## LaTeX Layout Example

An example LaTeX document (`example_latex_layout.tex`) is provided showing a comprehensive layout with:

**Structure:**
- Single table environment with two columns separated by headers "Settings" and "Results"
- Vertical dividing line between columns

**Left Column (Settings):**
1. Material properties table (top)
2. Input parameter tables (bottom)
   - Static constants ($\vec{x}_b$, $\vec{v}_b$, etc.)
   - Function constants ($v_{ij,n}$, $\omega_t$, etc.)

**Right Column (Results):**
1. Generated figure (top)
2. Error metrics table (bottom)

This layout efficiently presents all test information in a single, comprehensive table that fits on one page. The error table generated by the script can be directly copied into the template (it's already formatted without the outer `\begin{table}` wrapper).

**Key features:**
- Uses standard `\begin{table}` environment (not `\captionof`)
- Clear separation between Settings and Results
- Material properties included for completeness
- Compact yet readable layout
- Ready for publication

## Notes

- DEM data uses ALL points (no interpolation) for error calculations
- If normalization factor N is zero, uses N=1 to avoid division by zero
- Errors below machine precision (< 10^-14 %) are displayed as "< 10^-14" in output table
- DEM output file format includes velocities and angular velocities:
  ```
  t x1 y1 z1 x2 y2 z2 qx1 qy1 qz1 qw1 qx2 qy2 qz2 qw2 
  v1x v1y v1z v2x v2y v2z w1x w1y w1z w2x w2y w2z 
  f1x f1y f1z f2x f2y f2z t1x t1y t1z t2x t2y t2z
  ```
- Torque inbalance check uses T_i - T_j (different reference points)
- Force inbalance check uses F_i + F_j (Newton's 3rd law)
- All error metrics use vector magnitudes, not individual components
- 3D plot force axes have 10% margin for better visualization
- The script checks for matching number of time points between datasets
